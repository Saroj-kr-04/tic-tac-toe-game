# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game developed using **HTML, CSS, and JavaScript**.  
The game allows two players to play turn by turn with automatic winner detection.

## 🚀 Features

- Two-player gameplay (O and X)
- Turn-based game logic
- Automatic winner detection
- Displays winner message
- Reset Game functionality
- New Game option
- Interactive user interface
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Game Rules

- Player 1 uses **O**
- Player 2 uses **X**
- Players take turns placing their symbols.
- The first player to match three symbols horizontally, vertically, or diagonally wins.
- If all boxes are filled without a winner, the game is declared a draw.
